# 🧠 LARP Algorithmic Logic & Problem Solving

Welcome to my foundational software engineering repository! 

As a first-year computer science student, I realized that mastering syntax is not enough. The true core of software engineering lies in structured problem-solving. This repository bridges the gap between human logic and machine execution using **LARP**.

## 🎯 Purpose
This workspace is dedicated entirely to low-level logic design. Every project here is solved using:
1. **Structured Pseudocode:** Language-agnostic, step-by-step logical instructions.
2. **Visual Flowcharts:** Complete mapping of decision pathways and execution flow.

## 📂 Repository Architecture
The projects are categorized by logical complexity:
- `01_Basic_IO/` - Variables, memory assignment, and basic arithmetic.
- `02_Conditionals/` - Decision-making structures (If-Else, Switch cases).
- `03_Loops/` - Iterative processes and automated task handling.
- `04_Complex_Algorithms/` - Advanced problem-solving combining previous concepts.

## 🛠️ How to Review
Feel free to navigate into any folder. Inside, you will find a specific README, the `.lap` source file executable in the LARP environment, and exported screenshots (`.png`) of the flowcharts for quick visual review.
